## Pages

- Home: `index.html`
- Work: `projects.html`
- About: `about.html`
- Contact: `contact.html`
- Opportunities: `jobs.html`

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deployment

This is a plain static site. GitHub Pages should publish the `main` branch from the repository root (`/(root)`). The current project URL is:

`https://elwahizy.github.io/elwahizy.website/`

## Content policy

Only public, verifiable projects and links are described here. Personal contact details should be added only when they are ready to publish. Never commit passwords, API keys, or private documents.
